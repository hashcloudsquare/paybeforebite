# PayBeforeBite

Marketing website for **PayBeforeBite**, a modern restaurant POS and operations platform.

## Highlights

- Responsive SaaS-style landing page
- Restaurant POS product showcase
- Billing and invoice messaging
- Menu management and analytics positioning
- AI-powered restaurant insights section
- Early-access CTA
- FAQ
- Mobile navigation

## Run locally

Open `index.html` in a browser, or use any static web server.

## GitHub Pages

Enable **Settings → Pages → Deploy from a branch → main → / (root)**.

The site is intentionally dependency-light: HTML, CSS and vanilla JavaScript.

> Product positioning and tax examples on this marketing page are illustrative. Configure production tax rules according to the restaurant's applicable GST setup.
